# Suivi Tension

Application web pour noter la tension artérielle (systolique / diastolique) et le pouls de plusieurs membres de la famille.

- Les données restent uniquement sur l'appareil (stockage du navigateur). Rien n'est envoyé sur internet.
- Fonctionne hors ligne une fois ouverte une première fois.
- S'installe sur l'écran d'accueil (iPhone : Partager > Sur l'écran d'accueil ; Android : menu ⋮ > Installer l'application).

Outil de suivi seulement : il ne remplace pas l'avis d'un professionnel de la santé.
